# 🚌 Online Bus Ticket Booking Application

A web-based bus ticket booking system developed using **Java, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript**.
This application allows users to search buses, book tickets, and manage bookings through a simple and user-friendly interface.

---

## 🚀 Features

* 👤 User Registration & Login
* 🔍 Search Available Buses
* 🎫 Book Bus Tickets
* 📄 View Booking Details
* 🗂️ Booking History Management
* 💾 Database Connectivity using JDBC
* 🌐 Responsive Web Interface

## ⚡ Setup Instructions

1. Clone the repository

```bash
git clone https://github.com/santhoshbabu-dev/Online-Bus-Ticket-Booking-App.git
```

2. Import the project into Eclipse

3. Configure Apache Tomcat Server

4. Create MySQL Database

5. Update database credentials in JDBC connection file

6. Run the project on Tomcat Server
